# k3 — NixOS Media Server

Hostname: `k3` · IP: `192.168.20.26` · Role: Media server (Jellyfin + *arr stack)

## Hardware

| Component | Detail |
|-----------|--------|
| CPU | Intel, 6 cores, VT-x (`kvm-intel`) |
| RAM | 16 GB |
| OS Disk | `/dev/nvme0n1` — 238.5G NVMe (EFI + 8G swap + ext4 root) |
| Data Disk | `/dev/sda` — 1.8T HDD, mounted at `/mnt/data` |
| NIC | `eno1` — static `192.168.20.26/24`, gateway `192.168.20.1` |

## Media Stack (all native NixOS services)

| Service | Port | Data Dir | Purpose |
|---------|------|----------|---------|
| Jellyfin | 8096 | `/var/lib/jellyfin` | Media streaming |
| Sonarr | 8989 | `/var/lib/sonarr` | TV series management |
| Radarr | 7878 | `/var/lib/radarr` | Movie management |
| Prowlarr | 9696 | `/var/lib/prowlarr` | Indexer aggregator |
| Jellyseerr | 5055 | `/var/lib/jellyseerr` | Request management |
| qBittorrent | 8080 | `/var/lib/qBittorrent` | BitTorrent client (port 51413 for torrent traffic) |

All services run as systemd services under the `media` group (GID 2000).

## Storage Layout

```
/mnt/media/     ← NFS mount from NAS (192.168.20.31:/mnt/tank/media)
                   ├── TV/           (Sonarr managed)
                   ├── Movies/       (Radarr managed)
                   ├── downloads/    (qBittorrent downloads)
                   └── Downloads/    (alternate downloads)

/mnt/data/      ← Local 1.8T HDD (/dev/sda1, ext4)
                   Available for large local storage
```

## Deployment Workflow

```bash
# 1. Make changes locally, commit and push
git add servers/k3/ && git commit -m "update k3 config" && git push

# 2. On k3, pull and rebuild
ssh k3
cd ~/cn  # (or wherever the repo is cloned)
git pull
sudo nixos-rebuild switch --flake ./servers/k3#k3
```

## First-Time Setup After Deploy

1. **qBittorrent**: Login at `http://k3:8080` with `admin` / `adminadmin`, change password, set download path to `/media/downloads`
2. **Prowlarr**: Add indexers at `http://k3:9696`
3. **Sonarr**: Connect to Prowlarr + qBittorrent at `http://k3:8989`
4. **Radarr**: Connect to Prowlarr + qBittorrent at `http://k3:7878`
5. **Jellyfin**: Setup wizard at `http://k3:8096`, add media libraries pointing to `/media/TV` and `/media/Movies`
6. **Jellyseerr**: Setup at `http://k3:5055`, connect to Jellyfin + Sonarr + Radarr

## NFS Permissions

All services run under the `media` group (GID 2000). The NAS NFS export must
allow this group write access. If files are currently owned by a different GID
(from the old Fedora setup), you may need to adjust ownership on the NAS:

```bash
# On the NAS, or via NFS from k3:
chgrp -R 2000 /mnt/tank/media
chmod -R g+rw /mnt/tank/media
```

## Adding the Local HDD for Downloads

To have qBittorrent download to the local HDD instead of NFS (faster, less
network traffic), change the download path in qBittorrent's web UI to
`/mnt/data/downloads` and create the directory:

```bash
sudo mkdir -p /mnt/data/downloads
sudo chgrp media /mnt/data/downloads
sudo chmod g+rw /mnt/data/downloads
```

## Replacing k1 (Current Media Server)

Once all services are configured and tested on k3:

1. Stop containers on k1: `ssh k1 'podman stop -a'`
2. Update DNS/Caddy routes if needed
3. Update AGENTS.md machine registry
4. Decommission k1
