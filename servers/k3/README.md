## Initial Install (nixos-anywhere)

### Prerequisites

1. **Nix with flakes** on your local machine:
   ```bash
   curl --proto '=https' --tlsv1.2 -sSf -L https://install.determinate.systems/nix | sh -s -- install
   # Restart shell, then verify:
   nix --version
   ```

2. **Passwordless sudo** on k3 (nixos-anywhere requires it):
   ```bash
   ssh -i ~/.ssh/id_ed25519 crussell@192.168.20.26
   # On k3:
   echo "crussell ALL=(ALL) NOPASSWD: ALL" | sudo tee /etc/sudoers.d/crussell
   exit
   ```

3. **Verify access** from your local machine:
   ```bash
   ssh -i ~/.ssh/id_ed25519 -o IdentitiesOnly=yes crussell@192.168.20.26 'sudo whoami'
   # Should print: root
   ```

### Run the Install

```bash
cd servers/k3
nix flake lock

nix run github:nix-community/nixos-anywhere -- \
  --flake .#k3 \
  --target-host crussell@192.168.20.26 \
  -i ~/.ssh/id_ed25519 \
  --generate-hardware-config nixos-generate-config ./hardware-configuration.nix
```

This will:
1. SSH into k3 as `crussell`
2. Kexec into a NixOS installer ramdisk
3. Wipe `/dev/nvme0n1` and partition it (EFI + swap + root)
4. Install NixOS with your config
5. Generate `hardware-configuration.nix` locally
6. Reboot into NixOS

**The install wipes the NVMe.** All data on `/dev/nvme0n1` is destroyed. `/dev/sda` is untouched.

### Post-Install

```bash
# Clear old host key (server identity changed after reinstall)
ssh-keygen -R 192.168.20.26

# SSH in with key (no password needed)
ssh -i ~/.ssh/id_ed25519 crussell@192.168.20.26

# Change your password from the default
passwd
```

## Updating

After making changes to the config:

```bash
# From k3 locally:
sudo nixos-rebuild switch --flake /path/to/repo/servers/k3#k3

# Or remotely:
nixos-rebuild switch --flake .#k3 --target-host crussell@192.168.20.26
```

## Adding the HDD (/dev/sda)

When ready to use the 1.8T drive, add a second disk entry to `disk-config.nix`:

```nix
disk = {
  main = { ... };  # existing nvme0n1 config
  data = {
    device = "/dev/sda";
    type = "disk";
    content = {
      type = "gpt";
      partitions = {
        data = {
          size = "100%";
          content = {
            type = "filesystem";
            format = "ext4";
            mountpoint = "/data";
          };
        };
      };
    };
  };
};
```

Then rebuild.
